# Turkish correspondence SFT pilot

Five synthetic examples for user review, written directly by an AI assistant in a chat session (AI-written, not human-written and not human-reviewed; the owner approved the use). Exact backend model revision, sampling parameters and seed were not exposed. No external generation or translation API was used. This is a pilot, not an approved training release; do not expand to the planned 80 rows before user approval.

`pilot.json` contains a JSON array; `pilot.jsonl` contains the same five objects, one per line, in the originally requested format. Both are UTF-8 and preserve the four requested fields. The generation specification is the user's request in the conversation: distinct Turkish correspondence scenarios, natural Turkish, no emojis or placeholders, 40–160 words unless explicitly limited, and exclusion of the six held-out scenario families listed there.

Validation: both formats parse and contain identical objects; five unique IDs, types, prompts and answers; ordinary answers meet the word range; mail-005 contains exactly two sentences (the dot inside 19.00 is not a sentence boundary); no emoji, replacement character, bracket placeholder or table delimiters in answers. Answers were reread for wording and consistency with their prompts. No evaluation prompts were consulted as generation seeds. Overlap checking against the repository's evaluation sets remains pending the user's checker. No training pack or experiment configuration was changed.

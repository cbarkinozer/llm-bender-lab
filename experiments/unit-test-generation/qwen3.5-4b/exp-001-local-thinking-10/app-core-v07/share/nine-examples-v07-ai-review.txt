## Proposed interface agreement

Proposed API in `reflexmodels`:
- `Choice(state,question,options)` uses ordered dict option_id -> Unicode label, at least two unique choices. `Binary(state,question)` uses yes/no; `Ordinal(state,question,labels)` rejects duplicate labels. Empty questions or invalid option structure raise ValueError. `SharedStateDecisions(state,{question_id:decision})` keeps questions/options separate.
- `score_decision(decision,request_id=...,scorer=...)`: scorer(branch_text)->logit; stable softmax maps probabilities to original option IDs and selects max, ties resolved by declaration order. Branch text includes option label. `score_shared_state(batch,request_id=...,scorer=...,workers=1)` -> question_id -> result.
- `choice_response(choice,request_id=...,probabilities={id:p})` validates exact keys, finite p in [0,1] and normalization with 1e-6 tolerance, otherwise ValueError. Returns JSON-compatible dict including selected_option and option_probabilities and confidence (selected probability). Uncertainty is exposed by fallback_gate, not added to the strict response JSON. `protocol.request_to_json(request,request_id=...)` exposes state/options; `response_to_json(response)` roundtrips same dict without Unicode loss.
- `fallback_gate(response,min_confidence=...,min_margin=0,answerability_probability=None,min_answerability=...)` -> dict with fallback_required bool, reason_codes list. Low margin -> low_margin; insufficient answerability -> insufficient_evidence, independently of confident option.
- `metrics.classification_metrics(labels,probabilities,ece_bins=15)` -> accuracy,macro_f1,nll,brier,ece floats. labels zero-based; probability rows same normalized class count>=2. Empty input/invalid bins raise ValueError. Macro-F1 includes all probability columns (undefined per-class F1 contributes 0). NLL uses true-class probabilities; Brier sums squared multiclass errors then averages; ECE is weighted top-label confidence/accuracy discrepancy. Exact ties use first index. For [.75,.25] and [.25,.75] with correct labels, NLL=-log(.75), Brier=.125, ECE=.25.
Dependencies: Python standard library, pytest. Local model quality/calibration on real traffic remains an empirical/manual check.

- Decisions expose public .state and .question; Choice exposes .options, Ordinal exposes .levels. Ordinal option IDs are the level strings in declaration order; score_decision returns the selected level as selected_option.
- fallback_gate also returns confidence, margin (largest minus second-largest probability), normalized_entropy (-sum(p*ln(p))/ln(number_of_options)), accepted (inverse of fallback_required), and answerability_probability. Confidence below min_confidence adds low_confidence; no failed thresholds yields False with empty reason_codes.

## Proposed interface agreement

Proposed public API:
- `codelang_detect.detect(text)` returns the lowercase output label of the highest-scoring rule group, or "unknown" for empty/whitespace input or no positive evidence. - `codelang_detect.detector.PATTERNS` is the public developer-configuration mapping, read from that module on every `detect` call. Replacing it takes effect immediately; the function does not retain an import-time or first-call copy. It is insertion-ordered: output_label -> list[(compiled regex, positive weight)]. Keys are the labels returned by `detect`, including custom labels in controlled rule configurations.

Equal positive totals choose the first declared key, even when alphabetical order differs. All-zero scores return "unknown". This rule-based score is not a statistical confidence estimate.

- File-open/usage failure raises SystemExit(2), with useful stderr mentioning "can't open" and no stdout. Read/processing failure, including invalid UTF-8 bytes or closed stdin, raises SystemExit(1), with stderr starting "Error: Could not process the input." and no stdout. def test_weighted_evidence_not_match_count(monkeypatch):
    monkeypatch.setattr('codelang_detect.detector.PATTERNS', {'first': [(re.compile('alpha'), 1), (re.compile('beta'), 1)], 'second': [(re.compile('gamma'), 3)]})
    assert detect('alpha beta gamma') == 'second'


def test_equal_scores_use_first_declared_label(monkeypatch):
    monkeypatch.setattr('codelang_detect.detector.PATTERNS', {'zeta': [(re.compile('left'), 2)], 'alpha': [(re.compile('right'), 2)]})
    assert detect('left right') == 'zeta'


def test_cli_file_prints_one_label(tmp_path, monkeypatch, capsys):
    path = tmp_path / 'snippet.txt'
    path.write_text('def greet():\n    print("Merhaba dünya")\n', encoding='utf-8')
    monkeypatch.setattr(sys, 'argv', ['codelang-detect', str(path)])
    main()
    output = capsys.readouterr()
    assert (output.out, output.err) == ('py\n', '')


def test_cli_stdin_prints_one_label(monkeypatch, capsys):
    monkeypatch.setattr(sys, 'argv', ['codelang-detect'])
    monkeypatch.setattr(sys, 'stdin', io.StringIO('def square(x):\n    return x * x\n'))
    main()
    output = capsys.readouterr()
    assert (output.out, output.err) == ('py\n', '')

        main()
    assert error.value.code == 2
    output = capsys.readouterr()

import pytest
import torch

from _7_RMSNorm.pytorch import RMSNorm
from _4_RoPE.pytorch import RoPE, rotate_half


def test_rmsnorm_uses_last_dimension_and_learned_scale():
    layer = RMSNorm(2, epsilon=0.)
    with torch.no_grad():
        layer.weight.copy_(torch.tensor([2., 3.]))
    x = torch.tensor([[[3., 4.], [0., 5.]]])
    expected = torch.tensor([[[6. / (12.5 ** .5), 12. / (12.5 ** .5)], [0., 15. / (12.5 ** .5)]]])
    torch.testing.assert_close(layer(x), expected)


def test_rmsnorm_epsilon_keeps_zero_input_finite():
    layer = RMSNorm(3)
    torch.testing.assert_close(layer(torch.zeros(2, 3)), torch.zeros(2, 3))


def test_rmsnorm_backpropagates_expected_scale_gradient():
    layer = RMSNorm(2, epsilon=0.)
    x = torch.tensor([[3., 4.]])
    layer(x).sum().backward()
    torch.testing.assert_close(layer.weight.grad, torch.tensor([3., 4.]) / (12.5 ** .5))


def test_rotate_half_moves_and_negates_second_half():
    x = torch.tensor([[[[1., 2., 3., 4.]]]])
    torch.testing.assert_close(rotate_half(x), torch.tensor([[[[-3., -4., 1., 2.]]]]))


def test_rope_position_zero_is_identity_for_every_head():
    x = torch.tensor([[[[1., 2., 3., 4.], [5., 6., 7., 8.]]]])
    torch.testing.assert_close(RoPE(4, 8)(x), x)


def test_rope_rotates_sequence_axis_not_head_axis():

def test_greedy_generation_follows_unique_logit_maxima(budget, expected):
    from tiny_model import generate
    class SuccessorModel(torch.nn.Module):
        def forward(self, tokens):
            # Every position predicts (its current token + 1) mod 8 uniquely.
            logits = torch.full((*tokens.shape, 8), -10.0)
            return logits.scatter(-1, ((tokens+1)%8).unsqueeze(-1), 10.0)

Proposed public modules: `oracle_analysis` and `benchmark_workflow`.
- `OracleClass`: TRIVIAL for constant independent assertions, WEAK for SUT-derived coarse nullity/type/truthiness, STRONG for specific value/exception/state comparisons, UNKNOWN for unresolved helpers. `assert True` is TRIVIAL; `result=sut(); assert result is not None` is WEAK; `assert sut()==42` is STRONG; `assert helper(result)` is UNKNOWN. Strength is independent of correctness.
- `classify_oracles(source,sut_names=())` returns sites exposing `.oracle_id` and `.oracle_class`. `instrument_oracles(source,sut_names=())` returns `(instrumented_source,sites)` while preserving valid module headers and assertion semantics. Each reached check appends JSONL `{oracle_id:string}` to ORACLE_EXECUTION_FILE. Untrusted generated suites require isolation.
- `gate_outcomes(suite_passed,sites,executed_ids)` returns exactly `{execution_success,executed_nontrivial_gate,executed_strong_gate}`: success; success AND reached WEAK/STRONG; success AND reached STRONG. Classified but skipped/untaken assertions do not count.
- `run_task(task,root=...,sut_source=...,timeout_seconds=...,executor=None)` consumes `{id,source,sut_names,context,dependency}`. Reject nonpositive timeouts and unsafe IDs (empty, absolute, dot, parent or path-containing) with ValueError before writing or invoking an executor. Create root/id exclusively. Preserve raw source in generation.txt; instrument a separate copy for execution, retaining docstrings and future imports. A supplied SUT module exports sut().
- An executor is a callable `(run_dir,timeout_seconds)->report`. `executor=None` selects `DockerExecutor`, using a configurable pinned Python+pytest image, network disabled, bounded memory/processes, only the task directory mounted. `LocalPytestExecutor()` is solely for authored trusted fixtures, never untrusted generations. Its subprocess runs pytest with automatic plugins disabled. `DockerExecutor(image=...,infrastructure_grace_seconds=15)` allows explicit configuration; PYTEST_RUNNER_IMAGE configures the default image.
- `timeout_seconds` bounds pytest process startup, collection and execution. It excludes Docker startup. A separate infrastructure deadline bounds the outer container invocation; an infrastructure failure raises RuntimeError and is not mislabeled a suite timeout.
- Return `{task_id,context,dependency,outcome,returncode,stdout,stderr,backend,useful_success,reached_oracles}` plus optional timing diagnostics. `backend` identifies the actual executor. `reached_oracles` is a sorted unique list of oracle-ID strings. Outcome is passed (exit 0), runtime_failure (test failures), collection_error (collection/setup invocation error or no tests collected), or timeout (pytest deadline exceeded, returncode None). An all-skipped suite has outcome passed, useful_success=False and reached_oracles=[]. An empty/no-collected-test suite has collection_error and useful_success=False. A collected test without assertions can pass but is never useful. Useful success requires passed AND a reached WEAK/STRONG oracle. Save result.json with the actual outcome/backend.
- `summarize(eligible_ids=...,observations=...)` accepts observations `{task_id,useful_success}` and returns `{eligible,observed,missing,successful,success_rate}`. All eligible IDs form the denominator; zero denominator gives None. Unknown/duplicate observations or duplicate eligible IDs raise ValueError.
- `mutation_summary(eligible=...,valid=...,killed=...)` requires 0<=killed<=valid<=eligible. Returns these counts plus unconditional=killed/eligible and conditional=killed/valid; zero denominators give None. Invalid counts raise ValueError.
- `save_manifest(path,dict)` / `load_manifest(path)` preserve task_ids,model_revision,data_revision,code_revision,seed,timeout_seconds,network_disabled,context,dependency as JSON. No model inference or frozen-benchmark writes occur during these operations.
Dependencies: Python, pytest; Docker and a configured pinned image for isolated execution. Unit fixtures use the trusted local executor.

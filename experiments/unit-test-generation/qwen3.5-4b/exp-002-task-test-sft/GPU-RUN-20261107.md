## Validation and corrected failures

Protected scoring ran on local Linux Docker because the GPU container lacked a
Docker socket/nesting privileges. All5 authored reference controls passed and
all10 targeted faults were detected before model-score interpretation.

Preserved failures: initial engine initialization required enabling chunked
prefill; an actual-stack CPU test exposed extra Accelerate backward scaling,
which was compensated and retested; the first tiny evaluation OOM was fixed with
evaluation batch1 and removal of a large logits reshape copy. Both full runs
completed after these fixes. Failed logs remain in the archive.

Upstream reuse screening checked4 complete base files and5 files per candidate
against30 pinned upstream test files; no flags. This does not disprove pretraining
contamination. Source exclusion and reserved-family boundaries remain intact;
only scalar settings were consulted from the reserved paper study. Existing
cross-split taught-principle overlaps remain disclosed.

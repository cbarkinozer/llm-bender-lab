# LFM3-1.7B-Turkish-SFT-Dataset

The training set of [`cbarkinozer/LFM3-1.7B-Turkish-SFT`](https://huggingface.co/cbarkinozer/LFM3-1.7B-Turkish-SFT): **2,624 prompt and
answer rows** for supervised fine-tuning of `LiquidAI/LFM3-1.7B`. About 95% of the answers were written by the model itself
(**self-distillation**) and kept only if an automatic check passed. The rest are 137 synthetic Turkish rows.

## What is in it

| Category | Rows | English | Turkish | Thinking on | Answer origin |
|---|---:|---:|---:|---:|---|
| Math word problems | 1648 | 962 | 686 | 1347 | self-distilled |
| English general instructions | 299 | 299 | 0 | 249 | self-distilled |
| Code | 248 | 248 | 0 | 213 | self-distilled, unit tests passed |
| Tool calls | 292 | 292 | 0 | 236 | self-distilled, schema checked |
| Turkish general tasks | 57 | 0 | 57 | 0 | synthetic, corrected |
| Turkish emails | 80 | 0 | 80 | 0 | synthetic |
| **Total** | **2624** | 1801 | 823 | 2045 | |

- **Self-distilled rows (2,487):** the original `LFM3-1.7B`
  answered each prompt several times. A random answer that passed its check was kept: math needs the gold number, code must pass its
  unit tests, tool calls must match the schema, instruction prompts must satisfy their countable constraints. Turkish answers that came
  back in English or contained invented words were dropped. Prompts without a verified answer were dropped, nothing was substituted.
  No length cut was applied. Reasoning stays in English, also for Turkish prompts.
- **Synthetic rows (137):** 57 answers to native Turkish tasks that were corrected by a language model, and 80 polite emails written by
  a language model. They are **not reviewed by a human**.
- **Turkish prompts for math** are machine translations of English problems.
- Selection bias: answers exist only for problems the model already solves, so hard problems are under-represented.

## Format

One JSON object per line in `data/train.jsonl` (TRL prompt-completion format):

| Field | Meaning |
|---|---|
| `id`, `core_id` | row id and id of the prompt group |
| `category` | `math`, `en_general`, `code`, `tool`, `tr_general`, `tr_email` |
| `lang` | `en` or `tr` (language of the prompt) |
| `prompt` | list of chat messages (user turn, plus system or tool definitions for tool rows) |
| `completion` | list with the assistant message. With thinking on, the reasoning is inside `<think>...</think>` |
| `chat_template_kwargs` | `{"enable_thinking": true}` or `{"enable_thinking": false}`, pass it to the chat template when training |

```python
from datasets import load_dataset
ds = load_dataset("cbarkinozer/LFM3-1.7B-Turkish-SFT-Dataset", split="train")
```

## Held-out test split

`data/test.jsonl` (sha256 `70ec91dc566336406d55b5b9812cbfb411bb33e4b7ac9f8df88033a97c16a4f7`) is the **held-out test set** used for the "grade-school math, 100 test items" rows of the model
card: 100 problems from the GSM8K **test** split ([MIT](https://huggingface.co/datasets/openai/gsm8k)), each in English and in a Turkish
translation, 200 rows in total. It was never trained on: no test prompt or prompt-group id appears in `train`, checked when this
release was built, and a lexical leakage audit against the training pack was run during development.

| Field | Meaning |
|---|---|
| `id`, `core_id` | row id and id of the problem (the English and Turkish row share `core_id`) |
| `lang` | `en` or `tr` |
| `category` | `math_test` |
| `prompt` | chat messages, ends with the instruction to write the final answer as `Answer: <number>` (`Cevap: <sayı>` in Turkish) |
| `gold_answer` | the gold number from GSM8K |

Do not train on this split. The Turkish translations were produced and reviewed by a language model assistant only, **not validated by a
native speaker**, and some source problems are awkward or ambiguous as written. Scoring in the model card: thinking on, 4 samples per
prompt, the number after the answer marker must equal the gold number.

## Limitations

- Small (about 3M tokens) and dominated by math. Meant for a light SFT pass on LFM3-1.7B, not for general Turkish training.
- The Turkish prompts are machine-translated and the synthetic rows are not human-reviewed, so they can contain errors and unnatural
  Turkish. The text of the synthetic rows was produced with a commercial language-model assistant whose terms restrict some uses of its
  output. Re-check those terms before building on, redistributing or publishing models trained on these rows.
- Not checked for personal data or harmful content beyond the filters above.

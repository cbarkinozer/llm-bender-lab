# SFT core v01 (English side built 2026-11-22; Turkish side waits for the owner's translations)

Plan and to-do: [../SFT-CORE-PLAN-20261122.md](../SFT-CORE-PLAN-20261122.md). Status: prompts, checkers and worksheets built;
English-side sampling in progress (see the plan for the live state).

## What this is

A reusable set of prompt groups with an automatic checker per group (gold number, unit tests, gold tool call, countable
constraints), source ids, licenses and a split. It stores **no model answers**. A model's own answers form that model's *pack*
(`build_lfm3_sft_pack.py`); another architecture regenerates its own pack from the same core (feeding LFM3's answers to a
different model repeats the exp-010 to exp-015 failure of off-policy targets).

## Files

| File | Content |
|---|---|
| `prompts-en.jsonl` | core rows, 2,500 (schema below), deterministic and hash-ranked (`lfm3_sft_core.py build`) |
| `wrappers.json` | English instruction templates around problems (project-written; the Turkish versions come from the owner) |
| `worksheets/*.csv` | translation sheets for the owner, instructions in `worksheets/README.md` |
| `build-manifest.json` | pinned sources (revision, sha256, license), overlap audit, counts |
| `source-cache/`, `samples-local/`, `pack-local/` | ignored by Git (downloads, raw samples, training files) |

## Core row

`{id, category, split, source:{key,row}, langs?, en|tr:{...}, tools?, wrapper, thinking, check, reference}`. `check.type` is
`number` (gold, eval-v2 extractor), `toolcall` (gold calls, eval-v2 matcher), `mbpp` (asserts, executed on the pod only) or
`constraints` (countable constraints parsed from the prompt: word limits, bullet counts, sentence limits, JSON-only).
`thinking` (80% on, 20% off, fixed by hash) and the wrapper are stored so a pack cannot drift from the core.

## Categories

| Category | Rows | Source (pinned in the manifest) | License | Languages | Checker |
|---|---:|---|---|---|---|
| math | 1,000 | GSM8K train, 250 per solution-step bucket | MIT | EN + owner TR | gold number |
| math_final_test | 100 | GSM8K test minus the 152 eval-v2 items, 25 per bucket; never trained on | MIT | EN + owner TR (owner-checked) | gold number |
| code | 300 | MBPP full train+validation, minus 10 tasks that overlap HumanEval | CC-BY-4.0 | EN + owner TR (task sentence only; tests stay) | MBPP asserts |
| tool | 300 | glaive-function-calling-v2, first turn with one call whose arguments appear in the user text, minus BFCL names | Apache-2.0 | EN + owner TR | gold call |
| en_general | 300 | Dolly 15k (human-written instructions, 7 categories) | CC-BY-SA-3.0 | EN | EOS, English |
| tr_general | 500 | Turkish Atlas (native Turkish tasks, MIT): 250 with countable constraints, 150 with a context, 100 plain | MIT | TR | constraints, language, unknown words |

The MBPP reference solutions all pass their own tests (300/300, verified on the pod before any sampling). GSM8K train has no
exact or near-duplicate (Jaccard >= .8) of the eval and final-test questions. Dolly keeps its CC-BY-SA terms for those rows;
publishing the core needs a per-row license field.

## Rules that came from the earlier findings

- Reasoning for a Turkish prompt comes from the model reading the Turkish prompt; targets are a random verified sample, never the
  shortest, and nothing is cut for length (exp-016 trained the model to think briefly on Turkish).
- Turkish answers must pass a language check and an unknown-word filter (Zeyrek, 4% candidate and 4% English token limits).
- A prompt without a verified sample is dropped and counted, never filled with an English reply (that teaches language drift).
- No text generated by an Anthropic model is in the core (consumer terms). The translation tool the owner uses goes on the
  dataset card; check its terms before publishing.

## Rebuild

```
python scripts/datasets/lfm3_sft_core.py build                    # needs pyarrow, huggingface_hub, the Atlas download
python scripts/datasets/lfm3_sft_core.py render --lang en --output P.jsonl
python scripts/datasets/validate_lfm3_sft_core_translations.py --worksheets DIR --report R.json
python scripts/datasets/lfm3_sft_core.py render --lang tr --translations DIR --output P_tr.jsonl
# pod: generate_lfm3_sft_samples.py -> verify_lfm3_sft_samples.py (--allow-exec for MBPP) ; local: build_lfm3_sft_pack.py --zeyrek
```

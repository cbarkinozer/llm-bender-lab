## Rubric

Compare the opening with source and target independently of the complete response. Preserve propositions, tense, modality, polarity, entities and question/statement function. Exact reference equality is a string observation, not the entire semantic rubric. Use undercorrection only when an identifiable required edit survives in an aligned candidate; overcorrection only for an evidenced harmful unnecessary edit. Defensible edits beyond the reference do not automatically count as overcorrection. Meaning changes require explicit evidence. Wholesale unrelated responses are off-task, not automatically local meaning changes or missed spelling edits. Multiple defects can coexist; the first label summarizes the opening, while evidence notes secondary defects.

A heading/fragment is reported as such, not assumed to be a grammatical sentence. First-sentence extraction ends at initial sentence punctuation followed by whitespace/end, or the first newline; abbreviations/headings can yield a short span. Semantic judgments use the source/target and opening excerpt as well, not that heuristic alone. Multi-sentence inputs require checking more than their first sentence: gecturk-14063 explicitly discusses the next sentence too. Full-output success is assessed separately: extra prose is a task-format/stopping failure even when the opening is correct.

There is no basis to count that display artifact as model corruption or discard these 100 rows as replacement-character damaged. Zero U+FFFD does not prove absence of every possible mojibake or upstream textual defect; original generation bytes/tokenizer reconstruction were not independently audited. It establishes absence of this specific suspected stored corruption. No lossy repair, transliteration or re-decoding transformation was applied.

These judgments describe this saved continuation checkpoint and cohort only. No paired baseline review was performed; they cannot establish improvement/regression, causality from CPT, population correction accuracy, or correctness of unsupported continuation claims. Repeatedly inspected benchmark material remains evaluation evidence, not fresh holdout evidence. No training examples were created; no historical output, config, metric or Git history was changed.
